# MegaDrive
An Open-Source HardWare (OSHW) recreation of the Sega Mega Drive, modified to match the rare VA6.8 rev

The design tries to be a 1:1 recreation of the original IC BD M5 V6.8 PAL board.

## Notes
Capacitor values surrounding the MB3514 are unconfirmed and likely differ from the CXA1145 revisions.

The original PCB left C30 unpopulated, despite the mono audio buffer being present in the MB3514.

## List of Changes
-Modified original reproduction PCB to match the VA6.8

-Added extra trace for RAS0, 3 bodge wires on original PCB no longer required

-Modified volume slider footprint to fit original slider better

## Tips if you decide to make this/get it made
The dimensions are 240x191mm.

You will have to source the 2 SEGA custom chips from either a dead board or a chip dealer.
