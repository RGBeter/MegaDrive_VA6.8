# MegaDrive
An Open-Source HardWare (OSHW) recreation of the rare Sega Mega Drive VA6.8

The design tries to be a 1:1 recreation of the original IC BD M5 PAL V6.8 board.

## Changes and Notes
- PCB altered to use surface mount MB3514

- Original VA6.8 did not populate C30, despite the MB3514 having a mono audio buffer

- Some capacitor values may be inaccurate in the video section

## Tips if you decide to make this/get it made
The dimensions are 240x191mm.

You will have to source the 2 SEGA custom chips from either a dead board or a chip dealer.
